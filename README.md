# 📊 Tableau Projects

A collection of interactive data analytics and business intelligence dashboards developed using **Tableau**.

These projects demonstrate practical skills in data visualization, dashboard development, KPI analysis, filtering, trend analysis, geographic analysis, and business insights.

## 🛠️ Tools & Technologies

- Tableau
- Data Visualization
- Dashboard Design
- Calculated Fields
- Filters & Parameters
- KPI Analysis
- Trend Analysis
- Geographic Visualization
- Interactive Dashboards

## 📁 Projects

### 1. HR Analytics Dashboard

An interactive HR analytics dashboard designed to analyze employee workforce, attrition, demographics, job satisfaction, and departmental trends.

**Key Areas:**
- Employee Count & Active Employees
- Attrition Count & Attrition Rate
- Attrition by Gender
- Department-wise Attrition
- Employee Age Distribution
- Job Satisfaction Analysis
- Education-wise Attrition
- Age & Gender-based Attrition

[View Project →](./HR-Analytics-Dashboard/)

### 2. Credit Card Complaints Dashboard

An interactive dashboard analyzing credit card complaints, response performance, complaint trends, geographic distribution, issue types, and customer submission channels.

**Key Areas:**
- Total Complaints
- Timely Response & Closed Complaints
- In-Progress Complaints
- Weekly Complaint Trends
- State-wise Complaint Distribution
- Top Complaint Issues
- Company Response Analysis
- Complaint Submission Channels

[View Project →](./Credit-Card-Complaints-Dashboard/)
